# adr-020: Source Generator Strategy — Compile-Time Column Resolvers and Strongly-Typed Ordering Helpers

**Status**: Implemented *(v1.0 publish exclusion reversed — see note below)*
**Date**: 2026-08-14 (Updated: 2026-08-19)
**Deciders**: EricksonLopez.Specification architecture audit
**Category**: Build-Time / Source Generation / Release Strategy

> **Implementation Note**: The original decision to exclude `EricksonLopez.Specification.Generators` from the v1.0 `publish.yml` was subsequently reversed. The generator was fully implemented and is now **included in `publish.yml`**. This ADR remains as historical context; the current published state includes all generator capabilities described below.

---

## Context

The original v1.0 prototype generator contained empty stubs for `[Spec]`. Following the competitive audit and architectural refinement, the generator has been fully designed and implemented to provide high-value, zero-reflection code generation for NativeAOT and compile-time type safety.

---

## Implemented Capabilities

### 1. Compile-Time Zero-Reflection Column Resolvers (`[SpecColumnResolver]`)

Generates `IColumnNameResolver` implementations at compile time, eliminating runtime reflection in SQL translators:

```csharp
[SpecColumnResolver(typeof(Customer), Convention = NamingConvention.SnakeCase)]
public sealed partial class CustomerColumnResolver;
```

Generates:
```csharp
// <auto-generated/>
namespace MyDomain;

partial class CustomerColumnResolver : global::EricksonLopez.Specification.IColumnNameResolver
{
    public string Resolve(string propertyName) => propertyName switch
    {
        nameof(global::MyDomain.Customer.Id) => "id",
        nameof(global::MyDomain.Customer.Name) => "name",
        nameof(global::MyDomain.Customer.TotalPurchases) => "total_purchases",
        _ => throw new global::System.ArgumentException($"Unknown property '{propertyName}' for entity 'Customer'.", nameof(propertyName))
    };
}
```

### 2. Strongly-Typed Ordering Helpers (`[Spec]`)

Generates static, strongly-typed property ordering expressions for entities:

```csharp
[Spec(typeof(Customer))]
public partial class CustomerOrdering;
```

Generates:
```csharp
// <auto-generated/>
namespace MyDomain;

partial class CustomerOrdering
{
    public static readonly global::System.Linq.Expressions.Expression<global::System.Func<global::MyDomain.Customer, object?>> OrderById = x => (object?)x.Id;
    public static readonly global::System.Linq.Expressions.Expression<global::System.Func<global::MyDomain.Customer, object?>> OrderByName = x => (object?)x.Name;
    public static readonly global::System.Linq.Expressions.Expression<global::System.Func<global::MyDomain.Customer, object?>> OrderByTotalPurchases = x => (object?)x.TotalPurchases;
}
```

---

## Decision Drivers & Value Delivered

- **100% NativeAOT Safety**: Zero reflection calls during SQL translation or property lookup.
- **Zero Runtime Overhead**: Compile-time constant expressions and pattern matching switches.
- **Full IDE Autocomplete**: Strongly-typed ordering expressions provide compile-time safety against renamed properties.
- **Zero Roslyn Diagnostic Warnings**: Generator uses incremental pipeline architecture with proper diagnostic reporting (`SPEC004` when class is not marked `partial`).
